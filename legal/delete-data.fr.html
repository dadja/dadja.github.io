Cette page explique comment supprimer vos données de Ha!! Buggy, le jeu édité par {CO} sur Google Play et l'App Store. Les parents peuvent faire ces demandes pour leur enfant.

Données sur l'appareil

La progression, les pièces, les tenues, les réglages et les niveaux créés sont enregistrés uniquement sur l'appareil.

  1. Pour remettre le jeu à zéro sans le désinstaller : ouvrez Settings → Reset progress.
  2. Pour tout effacer de l'appareil : désinstallez Ha!! Buggy.

Données en ligne

Si vous avez utilisé les fonctions en ligne (partage de niveaux, nom d'affichage, adresse e-mail associée), demandez-nous de les supprimer :

  1. Écrivez à {EMAIL} avec l'objet Supprimer mes données.
  2. Indiquez votre nom d'affichage ou le code de partage d'un de vos niveaux, pour retrouver votre identifiant. Envoyez la demande depuis l'adresse associée si vous en avez ajouté une.
  3. Nous supprimons les données sous 30 jours et le confirmons par e-mail.

Données détenues par d'autres

  • Achats : les reçus sont conservés par Google Play ou Apple selon leurs propres règles.
  • Publicité : les données Google AdMob sont gérées par Google. Les adultes peuvent réinitialiser ou supprimer leur identifiant publicitaire dans les réglages du téléphone et gérer leurs choix sur myadcenter.google.com.
  • Succès : les profils Google Play Jeux et Game Center se gèrent dans votre compte Google ou Apple.
